# Нейросеть с нуля на C++ (Neural Network from Scratch)

Пошаговая методичка по созданию простого перцептрона на C++ без использования сторонних библиотек.

Цель — понять, как работают нейросети на самом низком уровне.

## 📚 Содержание

В репозитории представлены 8 уроков + финальный проект:
1. **Урок 1:** Что такое вес и откуда он берется (случайные числа).
2. **Урок 2:** Ошибка и подкрутка одного веса.
3. **Урок 3:** Крутим все веса на одном примере.
4. **Урок 4:** Все примеры + усреднение (эпоха).
5. **Урок 5:** Добавляем bias (свободную поправку).
6. **Урок 6:** Повторяем 100 000 раз (визуализация сходимости).
7. **Урок 7:** Зачем нужна sigmoid (переход к классификации).
8. **Урок 8:** Сохраняем веса в файл.
Полная теория и объяснения — в файле **`tutorial.md` или  `tutorial.pdf`**, которые находятся в папке `doc`.
## 🛠 Как запустить
Код написан на стандартном C++ (C++11 и выше). Сторонние библиотеки не требуются.

**Рекомендуемые IDE:**
*   **Visual Studio 2022** (создайте пустой проект C++ и скопируйте код).
*   **Visual Studio Code** (с установленным расширением C/C++ и компилятором MinGW/GCC).
*   Или любой другой компилятор C++ (g++, clang).

**Через терминал (g++):**
```bash
g++ main.cpp -o app
./app
```
